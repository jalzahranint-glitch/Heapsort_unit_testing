\f0\fs24 \cf0 # HeapSort Unit Testing with Pytest\
\
## Overview\
This project implements the HeapSort algorithm in Python and evaluates it using unit testing with Pytest.\
\
It also explores how generative AI tools such as ChatGPT can assist in creating and improving unit test cases through prompt refinement and human oversight.\
\
## Technologies Used\
- Python\
- Pytest\
- ChatGPT\
- Visual Studio Code\
\
## Project Description\
The HeapSort algorithm was implemented in `heapsort.py`. It sorts the input array in ascending order by building a max heap and repeatedly extracting the largest element.\
\
Unit tests were written to verify the correctness of the algorithm across basic and edge case inputs.\
\
## Test Cases Covered\
- Empty lists\
- Single-element lists\
- Duplicate values\
- Negative numbers\
- Floating-point values\
- Already sorted arrays\
- Reverse-sorted arrays\
- Randomized inputs\
- Property-based checks\
\
## AI Assistance\
ChatGPT was used to generate preliminary test cases and then improve them with additional edge cases, randomized inputs, and property-based style assertions.\
\
## Results\
All unit tests passed successfully using Pytest.\
\
The improved test suite achieved 100% statement coverage for the HeapSort implementation.\
\
## Files Included\
- `heapsort.py`\
- `test_heapsort.py`\
- `test_improved.py`\
- `report.pdf`\
- `screenshots/`\
\
## Conclusion\
This project demonstrates the implementation of HeapSort, the use of unit testing with Pytest, and the value of AI-assisted test generation in improving test quality and coverage.}
